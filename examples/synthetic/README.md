# Runnable synthetic protein–ligand analysis

**All compounds, group labels and counts are fabricated.** No patient, institutional, experimental or proprietary molecular data are included. Deliberately planted group differences illustrate the analysis; they are not evidence of pharmacological activity.

## Run

From the repository root, with Python 3.11 or newer:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-demo.txt
python examples/synthetic/run_demo.py
python -m unittest discover -s tests -v
```

On Windows, activate with `.venv\Scripts\activate`. No PyMOL, RDKit, PLIP or external docking software is needed for this example.

The script can be launched from any working directory. It uses a fixed seed (42) and creates 60 fabricated compounds, each with three related poses. Different NumPy versions can affect exact generated values; the tested versions are pinned.

## Outputs

| File in `output/` | Meaning |
| --- | --- |
| `synthetic_pose_counts.csv` | One row per compound/pose with explicit group label |
| `compound_mean_counts.csv` | One row per compound; mean contact counts across poses |
| `compound_presence.csv` | One row per compound; any-pose presence per feature |
| `compound_comparisons.csv` | All six planned tests, prevalence differences and adjusted p-values |
| `synthetic_interactions.svg` | Labeled synthetic distribution figure |

Generated outputs are ignored by git. The checked-in README preview was generated by this script and copied to `figures/synthetic_interactions.svg`.

## Statistical design

The compound, not each docking pose, is the analysis unit. Each compound has equal pose coverage. For each of three predefined features, presence means a count greater than zero in at least one pose. Stabilizer/control and destabilizer/control comparisons form one family of six two-sided Fisher exact tests, adjusted together with Benjamini–Yekutieli. No threshold or test is selected by minimum p-value. The effect size is the difference in contact prevalence (comparison group minus control).

The fixed presence rule discards count magnitude and is not automatically appropriate for every scientific question. Compound-level independence and reliable group assignment must be justified in real data. Equal pose counts do not eliminate pose-selection bias. Multiplicity correction does not validate an inadequate experimental design.

Use explicit groups `control`, `stabilizer`, `destabilizer`. Historical `strong` and `weak` labels are never silently recoded.

To analyze a separately authorized count CSV with the same schema:

```bash
python examples/synthetic/run_demo.py --input /path/to/pose_counts.csv --output-dir results/custom
```

Custom input produces tables only, avoiding a misleading synthetic label or a hard-coded three-pose caption on real data.
